# N4 単語帳 — 日文背單字網站

### 👉 線上版：https://oliverhuang20050304.github.io/Japanese_learning/

純靜態網頁（HTML / CSS / JavaScript），不需安裝任何東西。
線上直接開就能用，也可以把整個資料夾抓下來，**用瀏覽器打開 `index.html`**。

收錄 **941 個 JLPT N4 範圍單字**。每個單字都有：

- 中文解釋、假名標示、詞性
- **3 句日文例句 + 中文翻譯**（共 2,823 句），例句**逐字標注假名（ruby）**
- **動詞**：標注第一／二／三類，並附完整活用表（ます・ない・た・て・可能・意向・使役・受身・使役受身・條件ば・命令・禁止）
- **形容詞**：標注い形／な形，並附て形・否定・過去・條件・副詞形

## 單字來源

兩份清單取聯集：

| 來源 | 數量 |
|---|---|
| `src/tango-n4.pdf`（你提供的 N4 一覽表） | 903 |
| 先前自建清單獨有的字（多為「〜する」動詞與形容詞） | 46 |

詞性沿用 PDF 標註；動詞的類別（1/2/3）由程式判定，並以 105 個已知答案的動詞驗證通過。

## 學習方式

### 🎯 今日 — 間隔重複（SRS）

核心的背單字模式。每個單字記錄**熟練度等級**與**下次複習日**，只在你快要忘記時才把它推到眼前。

打開就看到「今天要複習 N 個、新學 M 個」，做完就收工，不用面對 941 個字。

看到日文 → 自己在腦中回想 → 看答案 → 依實際回想狀況按三個鈕之一：

| 你的回答 | 效果 |
|---|---|
| ❌ 不會 | 降回 Lv.1，明天再考，並在這一輪結束前再出現一次 |
| 🤔 模糊 | 維持原等級，明天再考 |
| ✅ 會 | 升一級，依下表延後 |

| 等級 | Lv.1 | Lv.2 | Lv.3 | Lv.4 | Lv.5 | Lv.6 |
|---|---|---|---|---|---|---|
| 答對後隔多久再考 | 1 天 | 3 天 | 7 天 | 14 天 | 30 天 | 90 天 |

按鈕上會直接標示「按下去之後多久會再出現」。Lv.4 以上視為**已熟**。

**新字的出現順序是隨機的，但固定**：首次開啟時把 941 個字洗牌成一份學習佇列存進瀏覽器，之後每天照這份佇列往下取。這樣既不會照著五十音順從「アイスクリーム」開始學，也不會每次隨機導致某些字重複出現、某些字永遠遇不到。

還有連續學習天數（🔥 streak）與熟練度分布圖。每日新字量可設 5／10／20／30 或暫停。

### 其他三種模式

| 分頁 | 功能 |
|---|---|
| 📖 **單字表** | 搜尋（單字／假名／中文／例句都可搜）、依分類篩選、只看收藏、隱藏已熟、遮住中文自我測驗、**依熟練度排序（不熟的先）**／五十音順／隨機、展開活用表。每個字都標示目前等級 |
| 🃏 **單字卡** | 點卡片翻面，背面顯示中文＋3 句例句，下方同步顯示活用表。可切換「日文→中文」或「中文→日文」、洗牌。鍵盤：<kbd>空白</kbd> 翻面、<kbd>←</kbd><kbd>→</kbd> 換卡、<kbd>S</kbd> 發音 |
| 🔍 **查字典** | 兩層查找：先查本站 941 字（離線、有例句與活用表），查不到再問**中文維基詞典**。單字表搜尋無結果時可一鍵跳過來查 |
| 📝 **測驗** | 四選一。四種出題方向（日→中／中→日／漢字→假名／**動詞分類**）、5／10／20 題、可只考收藏或未熟的單字。作答後立刻顯示正解與例句；**答錯的字會直接排進明天的 SRS 複習** |

## 檔案結構

```
index.html            頁面結構
css/style.css         樣式（含深色模式）
js/conjugate.js       活用引擎 — 由辭書形即時生成各種型態
js/srs.js             間隔重複排程引擎
js/dict.js            查字典（本地 + 中文維基詞典 API）
js/app.js             介面與功能邏輯
js/data/*.js          單字資料，依五十音分 24 個檔
tools/check.js        資料品質檢查腳本（941 字 × 3 例句）
tools/srs-test.js     SRS 排程邏輯測試（55 項）
tools/furigana.mjs    建置期工具：產生例句的假名標註
tools/furigana-fixes.mjs  假名標註的人工修正表

build-dist.mjs        把前端檔案收進 dist/ 供桌面版打包
src-tauri/            桌面版外殼（Rust）
```

> 單字來源 PDF（`src/tango-n4.pdf`）為他人著作，頁尾註明「僅供個人・教室學習使用，
> 禁止商用與再散布」，因此**未納入本 repo**，僅保留在本機。

活用形**不寫死在資料裡**，而是由 `js/conjugate.js` 依「辭書形 + 動詞類別」即時生成，
所以 941 個字不會出現漏字或活用不一致。不規則的部分（`行く` 的て形、`ある` 的否定、
`いらっしゃる／くださる` 的ます形與命令形、す 結尾動詞的使役受身…）都已個別處理。

## 例句的假名標註

例句的第三個欄位是括號記法的假名標註，執行時再轉成 `<ruby>`：

```
朝[あさ]は元気[げんき]に挨拶[あいさつ]をしましょう。
```

由 `tools/furigana.mjs` 產生（用 kuromoji 斷詞取讀音），**在建置期算好寫進資料**，
所以 app 執行時不需要載入 41MB 的辭典。改完例句後重跑：

```bash
node tools/furigana.mjs
```

它會檢查「把所有 `[...]` 移除後必須還原成原句」，並拿標註結果和字典讀音互相比對。

kuromoji 用的是通用辭典，在**數字＋量詞**（九時=くじ 不是 きゅうじ、一人=ひとり 不是 いちにん）
與**同形異讀**（表 おもて／ひょう、方 かた／ほう）上會判斷錯，這些已逐一確認並寫進
`tools/furigana-fixes.mjs` 覆蓋。設定裡可切換「一律顯示／滑過才顯示／不顯示」。

## 朗讀語音

macOS 內建一批趣味語音（Eddy、Rocko、Grandpa…），而 `getVoices()` 常把它們排在最前面，
直接取第一個就會聽到怪腔怪調。程式改成替每個日文語音評分後挑最自然的：

| 優先序 | 語音 |
|---|---|
| 1 | Google 日本語（Chrome 才有） |
| 2 | Kyoko、O-Ren 等標準女聲 |
| 3 | Otoya、Hattori 等標準男聲 |
| 最後 | 趣味語音（清單中標示「趣味音效」） |

也可以在「今日」分頁自行挑選並試聽，選擇會被記住。
桌面版走系統語音（沒有 Google 語音），預設會用 Kyoko。

> 想要更好的音質：**系統設定 → 輔助使用 → 朗讀 → 系統語音**，把 Kyoko 下載成加強版。

## 查字典

免費的日文辭典資料（JMdict、KANJIDIC）幾乎都是**日→英**，中文釋義大多在商業辭典裡且沒有免費 API。
實測後選用**中文維基詞典**，它是少數免費、有中文釋義、而且**有 CORS**（網頁版可直接呼叫、不需自架 proxy）的來源。

```
https://zh.wiktionary.org/w/api.php?action=query&format=json&origin=*&prop=extracts&titles=挨拶
```

`js/dict.js` 負責：

- **兩層查找**：先比對本站 941 字（瞬間、離線、有校對過的中文），再查維基詞典
- **節流**：兩次請求至少間隔 1.2 秒。維基詞典連續請求會回 `429`，實測十幾次就會被擋
- **本地快取**：查過的存進 localStorage（上限 400 筆、90 天），常查的字第二次是瞬間的
- **解析**：維基的內容簡繁混用、有些條目沒有分級標題、例句與釋義混排，這些都要處理。
  只取「純中文且前一行不是日文例句」的行當釋義，避開把例句翻譯誤當成釋義

已知限制：

- 覆蓋率不均。常用字大多有，冷門複合詞（如「応接間」）可能查無條目
- 維基的「形容詞」標題不區分 い／な，所以那欄只顯示「形容詞」，不擅自斷定
- 離線時第二層不可用，但本站 941 字照常運作

> 釋義取自中文維基詞典，授權 CC BY-SA 4.0，介面上有標註來源與原文連結。

## 新增／修改單字

打開 `js/data/` 裡對應的檔案，照同樣格式加一筆，存檔後重新整理頁面即可：

```js
{w:"単語",k:"たんご",p:"名詞",m:"單字",ex:[
  ["毎日十個の単語を覚えます。","我每天記十個單字。"],
  ["この単語の意味が分かりません。","我不懂這個單字的意思。"],
  ["単語を覚えるのは大変です。","背單字很辛苦。"]]},
```

| 欄位 | 意思 |
|---|---|
| `w`  | 單字（有漢字就寫漢字） |
| `k`  | 假名讀音 |
| `p`  | 詞性：`動詞I` / `動詞II` / `動詞III` / `い形容詞` / `な形容詞` / `名詞` / `副詞` / `接續詞` / `代名詞` / `連體詞` / `感嘆詞` / `疑問詞` / `助詞` / `數詞` / `其他` |
| `ex` | 3 組 `[日文例句, 中文翻譯, 假名標註]`（第三項由 `tools/furigana.mjs` 產生） |

分類（動詞／形容詞／名詞／副詞・其他）由 `p` 自動推導，不用自己寫。

改完務必跑一次檢查：

```bash
node tools/check.js            # 檢查全部
node tools/check.js a1.js      # 只檢查某個檔
```

它會檢查每個字是否有 3 句例句、例句是否真的用到該單字（會比對所有活用形）、
是否混入英數字母、句尾標點、例句重複、單字重複。

## 桌面版（macOS app）

用 [Tauri](https://tauri.app) 包成原生 `.app`。它使用 macOS 內建的 WebKit，**不像 Electron 得整包 Chromium**，成品約 10MB 而不是 150MB。

```bash
npm install          # 只需第一次
npm run app:build    # 產出 .app 與 .dmg
npm run app:dev      # 開發模式，直接開視窗
```

產物位置：

```
src-tauri/target/release/bundle/macos/N4 単語帳.app
src-tauri/target/release/bundle/dmg/N4 単語帳_1.0.0_aarch64.dmg
```

**網頁版與桌面版共用同一份前端程式碼**（`index.html` / `css` / `js`），
`build-dist.mjs` 只是把它們收進 `dist/` 給 Tauri 打包，不會分叉成兩套。
所以之後加功能照常改前端就好，網頁版 `git push` 自動更新，桌面版重跑一次 `npm run app:build`。

原生選單列：

| 選單 | 內容 |
|---|---|
| N4 単語帳 | 關於、隱藏、結束（⌘Q） |
| 編輯 | 復原／剪下／拷貝／貼上／全選（讓搜尋框能用 ⌘C ⌘V） |
| 檢視 | 今日 ⌘1、單字表 ⌘2、單字卡 ⌘3、測驗 ⌘4、切換深色 ⌘D、全螢幕 |
| 視窗 | 最小化、關閉視窗 |

### 兩件要知道的事

- **學習紀錄不共通**：localStorage 依來源隔離，桌面版與瀏覽器版的進度是兩份。
- **未經簽章**：自己用沒問題（第一次開啟若被 Gatekeeper 擋下，於 app 上按右鍵 →「打開」即可）。
  要發給別人而不跳警告，需要 Apple Developer 帳號做簽章與公證。

## 小提醒

- 日文發音需要系統有日文語音；macOS／iOS 內建，Windows 可能要另外加裝。
- 網址可加 `#list`、`#card`、`#quiz` 直接跳到指定分頁。
- 學習紀錄存在瀏覽器的 localStorage，換瀏覽器或清除資料就會歸零。
- 例句由我撰寫，文法控制在 N4 程度內，並經腳本驗證用字正確，但未經母語者校對。
